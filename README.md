# Codyssey 올인원 미션 1-2

## 프로젝트 개요

의료 IT, 인공지능, 디지털 헬스케어를 주제로 한 Python 퀴즈 프로젝트입니다. 사용자가 퀴즈를 풀고 결과를 확인하며, 실행 간 진행 상태를 파일로 저장하는 프로그램을 만드는 것이 목표입니다. **현재는 프로젝트 문서와 기본 폴더 구조만 준비되어 있으며, 퀴즈 기능은 구현 예정입니다.**

## 퀴즈 주제와 선정 이유

- **주제:** 의료 IT·인공지능·디지털 헬스케어
- **선정 이유:** 의료 현장에서 활용되는 디지털 기술과 인공지능의 기본 개념을 퀴즈로 익히고, 기술이 건강 관리와 의료 서비스에 어떻게 연결되는지 살펴보기 위해 선정했습니다.

## 개발 환경 및 실행 방법

- 운영체제: Windows 11
- 편집기: Visual Studio Code
- 셸: PowerShell
- 언어: Python 3.12.10
- 버전 관리: Git
- 외부 패키지: 사용하지 않음 (Python 표준 라이브러리만 사용)

구현 완료 후 프로젝트 루트에서 다음 명령으로 실행할 예정입니다.

```powershell
python main.py
```

`main.py`의 콘솔 메뉴와 공통 숫자 입력 처리는 구현되었습니다. 퀴즈 동작은 **구현 예정**입니다.

## 필수 기능 목록

아래 기능은 모두 **구현 예정**입니다.

- 퀴즈 문항과 선택지를 화면에 표시
- 사용자 입력을 받아 정답 여부 판정
- 퀴즈 진행 및 점수 계산
- 결과 요약 표시
- `state.json`에 진행/결과 상태 저장
- 저장된 상태를 읽어 재실행 시 이어서 확인
- 잘못된 입력과 저장 데이터 오류에 대한 안내 및 처리

## 보너스 기능 (구현 예정)

1. 난이도별 퀴즈 선택
2. 문항별 해설 제공
3. 정답률과 최고 점수 기록
4. 문제 순서 무작위 섞기
5. 오답 문항 다시 풀기

## `state.json` 데이터 저장 구조

`state.json`은 프로그램을 종료한 뒤 다시 실행해도 진행 상태나 결과를 확인할 수 있도록 저장하는 JSON 파일로 계획하고 있습니다. **구조와 저장/불러오기 동작은 구현 예정**입니다. 예정 데이터 예시는 다음과 같습니다.

```json
{
  "version": 1,
  "current_question": 0,
  "score": 0,
  "answered_questions": [],
  "completed": false
}
```

필드의 의미와 검증 규칙은 구현 단계에서 확정합니다. `.gitignore`에서 `state.json`을 제외하지 않으므로 실제 저장 파일은 Git 추적 대상으로 둘 수 있습니다.

## Git 및 테스트 안내

- Git 저장소는 프로젝트 루트에서 관리합니다. 변경 내역은 `git status --short`로 확인할 수 있습니다.
- 작업 단위가 끝나면 변경 파일을 검토하고, 커밋과 원격 저장소 작업은 프로젝트 진행 절차에 따라 수행합니다.
- 기능 구현 후 Python 표준 라이브러리의 `unittest` 등을 사용해 입력 처리, 점수 계산, 저장 및 재실행 동작을 확인할 예정입니다.
- 테스트 코드와 퀴즈 기능은 **구현 예정**입니다.

## 개발 원칙

이 프로젝트는 **Python 표준 라이브러리만 사용**합니다. 외부 라이브러리나 패키지를 설치하지 않고, JSON 처리 등 필요한 기능은 표준 라이브러리로 구현할 예정입니다.
