# Codyssey 올인원 미션 1-2

## 프로젝트 개요

의료 IT, 인공지능, 디지털 헬스케어를 주제로 한 Python 콘솔 퀴즈 프로젝트입니다. Python 표준 라이브러리만 사용합니다.

## 실행 방법

프로젝트 루트에서 실행합니다.

```powershell
python main.py
```

메뉴의 `1. 퀴즈 풀기`를 고르면 5개, 10개, 15개 중 문제 수를 선택합니다. 기본 퀴즈와 현재 추가한 문항 중 지정한 수만큼 중복 없이 무작위 출제하며, 각 문제에 네 선택지를 표시합니다. 답은 1~4번으로 입력합니다. `h`를 입력하면 힌트를 확인할 수 있고, 요청 1회마다 최종 점수에서 10점 감점됩니다. 점수는 정답 비율을 반올림한 뒤 힌트 감점을 적용하며 0점 아래로 내려가지 않습니다. 게임이 끝나면 정답·오답 개수와 100점 만점 점수를 표시합니다. 잘못된 입력은 다시 입력하도록 안내하며, Ctrl+C 또는 입력 종료(EOF)는 프로그램을 안전하게 종료합니다.

`2. 퀴즈 추가`에서는 문제, 선택지 네 개, 정답 번호, 힌트를 입력해 문항을 등록할 수 있습니다. 문제와 선택지는 비어 있지 않도록 확인하며 입력 앞뒤 공백을 제거합니다. 추가 문항은 `state.json`에 저장되어 재시작 후에도 유지됩니다.

`3. 퀴즈 목록`은 저장된 기본 및 사용자 문항을 순서대로 출력합니다. 각 항목에 순번·문제·선택지 네 개만 표시하며 정답과 힌트는 목록에 표시하지 않습니다. 목록 확인 후 메인 메뉴로 돌아옵니다.

`4. 점수 확인`은 최고 점수와 모든 완료 게임의 기록을 보여줍니다. 점수가 동률이면 기존 최고 점수 기록을 유지합니다. 기록에는 완료 시간, 푼 문제 수, 정답 수, 최종 점수가 포함됩니다.

## 저장 데이터

게임 상태는 프로젝트 루트의 `state.json`에 UTF-8 JSON으로 저장합니다. 파일이 없으면 기본 퀴즈 15개와 빈 점수 기록으로 시작하고, 손상되었거나 읽기 오류가 있으면 안내 후 같은 기본값으로 복구합니다. 파일 쓰기는 임시 파일을 만든 뒤 교체하는 방식으로 처리하며, 쓰기 오류는 안내합니다. `state.json`은 개인 실행 기록이므로 Git에서 제외됩니다.

```json
{
  "version": 1,
  "quizzes": [
    {"question": "문제", "choices": ["가", "나", "다", "라"], "answer": 1, "hint": "힌트"}
  ],
  "high_score": {
    "datetime": "2026-11-10T12:00:00+09:00",
    "questions": 5,
    "correct": 4,
    "score": 80
  },
  "history": []
}
```

## 파일 구성

```text
main.py                 # 콘솔 메뉴와 실행 흐름
quiz.py                 # 개별 Quiz 모델과 답안 판정
quiz_data.py            # 기본 퀴즈 15문항
quiz_game.py            # 무작위 퀴즈 진행과 점수 계산
tests/                  # unittest 자동 테스트
```

## 테스트

전체 테스트는 다음 명령으로 실행합니다.

```powershell
python -m unittest discover -s tests -v
```
