# Codyssey 올인원 미션 1-2

## 프로젝트 개요

의료 IT, 인공지능, 디지털 헬스케어를 주제로 한 Python 콘솔 퀴즈 프로젝트입니다. Python 표준 라이브러리만 사용합니다.

## 실행 방법

프로젝트 루트에서 실행합니다.

```powershell
python main.py
```

메뉴의 `1. 퀴즈 풀기`를 고르면 5개, 10개, 15개 중 문제 수를 선택합니다. 기본 퀴즈 15개 가운데 지정한 수만큼 중복 없이 무작위 출제하며, 각 문제에 네 선택지를 표시합니다. 답은 1~4번으로 입력합니다. 게임이 끝나면 정답·오답 개수와 100점 만점 점수를 표시합니다. 점수는 정답 비율을 반올림해 정수로 계산합니다. 잘못된 입력은 다시 입력하도록 안내하며, Ctrl+C 또는 입력 종료(EOF)는 프로그램을 안전하게 종료합니다.

`2. 퀴즈 추가`에서는 문제, 선택지 네 개, 정답 번호, 힌트를 입력해 문항을 등록할 수 있습니다. 문제와 선택지는 비어 있지 않도록 확인하며 입력 앞뒤 공백을 제거합니다. 추가한 문항은 현재 실행 중인 퀴즈 목록에 포함되어 메뉴 1번의 출제 대상이 됩니다. 프로그램을 재시작하면 추가 문항은 초기화됩니다. 힌트는 입력해 저장하지만 게임 중 표시하지 않습니다.

`3. 퀴즈 목록`은 현재 게임이 보유한 퀴즈를 순서대로 출력합니다. 기본 문항과 현재 실행 중 추가한 문항을 함께 보여 주며, 각 항목에 순번·문제·선택지 네 개만 표시합니다. 정답과 힌트는 목록에 표시하지 않으며, 목록을 확인한 뒤 메인 메뉴로 돌아옵니다. 퀴즈가 없으면 등록된 문항이 없다고 안내합니다. `4. 점수 확인`은 후속 구현 예정입니다.

## 파일 구성

```text
main.py                 # 콘솔 메뉴와 실행 흐름
quiz.py                 # 개별 Quiz 모델과 답안 판정
quiz_data.py            # 기본 퀴즈 15문항
quiz_game.py            # 무작위 퀴즈 진행과 점수 계산
tests/                  # unittest 자동 테스트
```

## 테스트

전체 테스트는 다음 명령으로 실행합니다.

```powershell
python -m unittest discover -s tests -v
```

## 향후 기능

- 점수 확인 메뉴
- 진행 상태와 결과 저장 및 불러오기
- 힌트, 해설, 오답 다시 풀기 등 확장 기능
